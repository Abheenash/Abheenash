### ☁️ Featured AWS projects — build → ship → operate

**[Serverless File Share](https://github.com/Abheenash/serverless-file-share)** — *build securely* · [live demo](https://share.abheenash.com)
Self-destructing encrypted file sharing. S3 · Lambda · API Gateway · DynamoDB (TTL) · KMS · CloudFront — all in Terraform, shipped with a keyless-OIDC CI/CD pipeline.

**[Secure Container Pipeline](https://github.com/Abheenash/secure-container-pipeline)** — *ship securely*
A containerized service on ECS Fargate behind a DevSecOps pipeline that blocks insecure code from merging (gitleaks · Checkov/tfsec · Trivy) — proven by automatically blocking a PR with a planted secret.

**[Cloud Observability & Incident Response](https://github.com/Abheenash/cloud-observability-sre)** — *operate reliably*
Golden-signals dashboard, X-Ray tracing, SLOs, alarms, and a synthetics canary on a live service — validated with a failure-injection drill (an alarm caught an induced outage in ~60s).
